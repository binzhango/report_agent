---
name: validation-repair
description: Diagnose report preview failures and apply bounded layout or content
  repairs.
---

Read the actual diagnostics. Correct missing bindings, types, column names, and content length before retrying. Never silently drop rows, change parameter meanings, or invent missing data to make a render pass. For slide overflow split text into multiple blocks or aggregate data only with agreement. Attempt at most two repairs per user request, then explain what is unresolved. A successful file creation is not proof of visual quality: show the rendered preview for user review. A revision invalidates acceptance of an older preview.
