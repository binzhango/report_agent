CSV uses query=data. XLSX uses query=data for the first sheet or the exact sheet name. File filters map query params to {column, op, type}; operators eq/ge/gt/le/lt and optional type=date are supported. SQL uses configured SQLite or PostgreSQL connections and named binds, with result limits and read-only execution. HTTP uses configured endpoint names and GET query params; responses must be a JSON records list or configured top-level records_key. Upload and endpoint limits are enforced by the application. Credentials live in server environment/configuration, never report definitions.
